============
qmcontrol
============

Authors
=======
Q Magnetics www.qmagnetics.com

About
=====

Q Magnetics GUI spectrometer control desktop application

Usage
=====

Run 'python run.py' from within the project folder

If you have no Q Magnetics hardware, choose Global>Service>simulate in the settings tree.

To use with Q Magnetics hardware you must install the Opal Kelly USB drivers.
